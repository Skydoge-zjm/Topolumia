# 决策：类型核心与自由内容分层

状态：采用。文献核心已实现，其他科学节点专属核心仍需逐项设计；统一节点组复用共同内容机制。

固定研究栏目会迫使用户适应产品；完全取消类型结构又会让文献、实验、假说都变成同一种内容堆积。

因此保留节点最小系统身份及类型核心，将扩展研究内容交给自由创建的内容块。系统只定义内容能力和处理合同，用户决定标题、数量、顺序与材料。

同一内容可以有结构化数值、原文截图和文件等多种表示。保留来源和表示关系，避免把转录当作原件，或在切换编辑器时丢失研究信息。

[节点组](../../product/business/node-groups.md) 具有集合核心、独立自由材料、成员与正式关系。它复用科研对象的内容能力，类别只描述集合用途，无需把简单整理与研究聚合拆成两种对象。成员加入组不复制正文，不把组合本身变成新的科学论断。

代价是模型、编辑和渲染需要同时处理 payload、representation 与来源。通过单一 Schema、最小 patch 和往返编辑验证维护一致性，不为每种论文预设强制模板。

业务：[科研模型](../../product/business/research-model.md)。机制：[内容块模块](../modules/content-blocks/README.md)。
