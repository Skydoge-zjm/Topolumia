# 决策：科研历程、时间活动与执行日志分开

状态：采用，当前实现有独立存储与页面职责。

拓扑表达研究逻辑，定期组会表达时间活动，Agent Trace 表达执行过程。若把它们混在“研究记录”里，会用大量工具噪声淹没真正的科研进展，也让活动被迫成为逻辑节点。

研究记录页面组合自动领域历程与人工/Agent 参与的活动纪要。组会、阅读、复盘和周期系列可以引用科研节点，但不自动成为拓扑节点。候选提出与审批属于领域行为，应进入历程；逐字符输出、MCP 调用和普通回复留在会话及审计中。

代价是需要在提交边界捕获真实科研动作，并维护活动引用的历史快照。使用领域事件与事务，而不是从聊天文本猜测“发生了什么”。

业务：[科研模型](../../product/business/research-model.md)。机制：[研究记录模块](../modules/research-records/README.md)。
