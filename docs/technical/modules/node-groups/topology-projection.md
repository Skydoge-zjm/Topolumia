# 节点组拓扑与折叠

状态：已实现。业务语义由 [节点组](../../../product/business/node-groups.md) 定义；对象与版本见 [模块](README.md)。

## 正式图与显示图

正式拓扑分别包含 nodes、groups 和 edges。节点/组摘要来自各自权威对象，所有边采用类型化 `from/to: ResearchObjectRef`，拥有稳定 ID 和 revision。正文和所有成员详情不进入默认画布响应。

画布适配为布局元素时使用由类型化引用生成的稳定 key；不得依靠给任意 ID 添加/删除 group: 前缀来猜对象身份。展开与收起两种形态引用同一个组对象。

成员与父子层级独立于 edges，不为了布局写入正式“包含”逻辑边。组标题、背景框和成员连线是专用显示元素，有明确样式和语义，不参与科研邻居查询。

## 容器的两种状态

收起与展开始终保留同一容器身份。收起尺寸不随成员数无限增加：组名、数量、有限区域内的小点形成缩略图，点的位置优先复用已知展开布局。点击容器预览或明显的展开入口进入；详情是独立操作，不在普通展开时离开画布。

展开后成员卡片和子组位于可见容器范围内，标题栏提供收起、重新聚焦与查看详情。容器背景与边框仅表达成员范围，不生成科研逻辑边。共享节点的多个加入位置无法唯一包含时放在共同祖先或外部共享区域，并明确所属组，不能按 ID 选择某一组。

布局先自底向上计算展开容器的内部布局和尺寸，再把顶层容器作为有实际尺寸的元素参与外部布局。无内部科研关系的成员采用紧凑排列；有内部关系时利用既有 ELK Worker。容器标题和内边距保留可操作空间，背景、边线、节点和操作分别分层，内部关系不能被背景遮挡。

组级边连接容器边界，内部节点关系连接节点本身。收起后的成员对外投影仍保留原始关系。布局中使用的包含结构不是科研逻辑关系。空组也有容器、入口和正式端点。

## 摄像机与位置连续性

用户展开组前记录摄像机、当前布局及焦点层级。展开布局完成后，镜头平移/缩放到容器，使最长受限方向占画布约 80%，保留至少一圈边缘空间；使用实际画布宽高，不能用写死的视口高度。外围能看到通往外部对象的线，外部节点在屏外时提供可定位的名称提示。

收起时恢复对应展开前的视角和根对象位置；嵌套返回恢复上一层。刷新页面保留展开状态但无需持久化整个摄像机历史；初次进入自动适配当前图或明确指定的聚焦组。

手动拖动、滚轮缩放和再次展开/收起取消进行中的摄像机动画，以最新交互为准。减少动态效果设置下直接更新。拖动容器标题平移该容器及其实际布局子孙；共享区域节点不被错误带走。内部拖动保存相对位置并受父容器边界约束。

从详情链接或组选择器进入聚焦时，一次性消费展开意图，再移除 URL 中的动作参数；状态更新和导航过渡不能反复触发布局。布局任务与逐帧摄像机状态独立，过期任务取消后不得覆盖新场景。搜索临时揭示成员，选择模式保留原展开状态；聚焦主要移动镜头，其他科研对象仍保留在全图中。

聚焦时绘制组内关系及所有与当前组范围相连的对外关系，无关关系临时隐藏，避免其他实验系列的线穿过当前容器。返回之前视角后恢复相应关系集合；正式拓扑和 Agent 读取不受这一显示筛选影响。

持久位置带实际布局父对象，只有父对象一致时才复用相对坐标。展开中、收起中和已保存布局使用同一对象 key，禁止把同一组画成另一个临时科学节点。

容器的背景、边框与交互层使用同一套绝对坐标和尺寸，几何与点击区域必须重合。展开导航保存之前的展开集合；返回同时恢复镜头、布局和这一集合，避免从侧栏进入子组后只恢复镜头却留下错误的祖先展开状态。全图适配不放大超过正常比例，保持收起容器紧凑。

## 收起算法

先以完整、已授权的正式图计算范围和计数，再应用浏览筛选；不能拿搜索过滤后的部分成员重写组的总数或成员身份。

1. 计算每组直接成员、子组和递归去重节点集合，保留真实加入位置。
2. 取得当前收起组，移除已有收起祖先的组，得到有效收起根 C。被收起祖先包住的子组，其入口一并折叠到祖先，但身份仍可查。
3. 对每个节点 n 计算覆盖它的有效收起根，并检查其直接加入的组是否均位于同一个收起根内。没有覆盖则显示原节点；仅一个根且所有直接加入位置都在其中，才收起到该组。覆盖多个根，或在根外还有直接加入位置的节点，保留为共享成员，避免遮住其他展开组中的节点。
4. 组入口映射到自身或最近的有效收起祖先；节点映射到自身或唯一覆盖组。共享节点始终映射到自身。
5. 遍历所有正式边一次，记录原始边及端点后计算可见端点。两端映射到同一入口的边计入内部隐藏数量，其余形成直接边或投影边。
6. 返回视图元素、边来源清单、组完整/收起/共享数量与内部边计数，正式对象不变。

同一输入及浏览状态产生同一输出，不依赖组数组顺序或 ID 排序决定成员归属。展开祖先仅通过子组间接包含节点，不算一个额外的直接加入位置；祖先和子组都显式加入同一节点时则保留两个实际位置。聚焦视图只在当前范围内计算显示归属，同时提示其他组归属。

## 直接边与投影边

未改变端点的正式边保留自己的可点击身份。改变至少一端显示位置的边是投影边，记录 originRelationIds、原端点和可见端点，不获得可正式编辑或批准的身份。

投影聚合键至少包含可见 from/to、方向、关系类型和边类别。直接组边与成员投影边不能合并。两条类型相同但说明不同的投影边允许合并显示计数，展开必须展示各自说明，不能把第一条说明当成整组结论。

例如 D→G 是一条直接组边，E1→S 是成员边。收起 G 后可以同时显示 D→G、G→S（直接总结边）、G→S（成员投影，1 条）；后两者必须可区分，不能删除一条来强行满足“一条出边”。

当某条边因收起祖先而映射时，即使原本连接子组，也保留其原始子组身份。主边标记只属于真实的直接组关系，不能挂到由成员边聚合出的临时边上。

关系可以显式连接组与自身成员；收起时计入内部关系，展开后恢复。图的循环科研推理允许存在，禁止的是成员层级循环及对象到自身的逻辑边。

## 主边、筛选与聚焦

主入边/出边通过组对象中的指针关联正式边，方向匹配后才生效。它们影响强调，不改变正式边集合。被外层组收起时保留原始主边标记，不能把它误当外层组的主边。

聚焦组时展示递归范围、子组以及相关外部端点的轻量上下文；外部端点有“范围外”提示，进入后可返回。部分视图返回完整范围计数与本次可见数，不以当前显示数量代替事实。

搜索可临时展开命中的包含路径；多归属命中可显示共享节点与组导航。退出搜索恢复用户原有收起集合，不修改服务端组对象。

浏览状态按 userId/projectId 隔离。展开/收起、筛选和重新布局不能进入 ResearchChangeService；改成员、排序、主边或父组必须进入正式写入。

## 复杂度与验证

单次投影建立节点/组/边索引；无环层级可缓存递归范围，复杂度按实际成员覆盖量和边数增长，避免每画一条边再递归遍历整组。大量成员仍按服务端目录分页，画布只接收轻量身份、层级和必要成员 ID，不夹带正文。

验证同时覆盖摄像机留白、组内几何包含、组拖动与视角恢复。投影继续验证：直接组边在空组和展开时仍存在；父组包含子组的关系投影可还原；收起组之间及收起/展开组之间的共享节点不被抢占；重排输入不改变归属；直接边与投影边不混合；无边孤立成员仍可见；搜索后状态可恢复；投影前后正式图相同。

关系类型、来源列表和计数在测试中核对具体事实，不仅检查画面节点数量。对详情开关与视口使用一条真实浏览器链路即可，不为每种颜色或间距写独立测试。
