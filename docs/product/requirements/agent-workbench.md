# Agent 工作台需求

依据：[Agent 协作](../business/agent-collaboration.md)。Codex、Claude Code、OpenCode 使用共同工作台；原生能力有差异时明确反馈，不另造三套会话界面。

## 会话与控制

- 创建、继续、切换会话时保持用户消息、历史内容与会话身份；新回合追加到原会话。
- 执行中可停止；输入为空时发送位置显示停止按钮，有新输入时允许排队，展示队列与失败恢复。
- 不设置整个研究任务的统一倒计时；应用进程意外结束后保留历史并解释中断。
- 会话容量只限制运行实例，归档、关闭和重启不按数量裁剪保存历史。
- 保存失败可见并可重试，不把未落盘误标为保存成功。

## 紧凑且可探索的展示

- 最终回复提供复制和保存科研笔记操作，中间回复不重复这些按钮。
- 推理、命令、MCP 等类型有不同图标；连续过程可折叠为按类别计数的一行摘要。
- 命令或 MCP 调用未展开时每项一行；逐项展开后命令、输入、输出各在有限高度内滚动。
- Topolumia 自有工具采用中英文语义名称；外部 MCP 不强行改名。结构化结果按结构展示，复制保留完整原输出。
- 连续 imageView 合并为图像组，展开显示缩略图，点击看大图并可关闭；临时文件消失后历史图像仍可查看。
- 用户可粘贴或选择受支持图片，发送给原生 Agent；草稿图片可以移除。
- 会话消息导航可定位用户消息并提供悬浮摘要；动效克制，支持减少动态效果。

## 两种审批

原生执行审批显示动作、范围和可选决定，按当前权限禁用不可用选项；与正文对齐，使用普通字体。Agent 原生提供的选择可以不同，但不可绕过应用的高风险审批权限。

科研候选在所属回合结束处显示可交互审批卡，支持预览、接受、拒绝和暂缓；没有权限时明确说明，Agent 不可自批。

## 配置

统一配置页提供少量常用输入与选择，以及可编辑原生文件。Codex 使用 TOML，Claude Code 使用 JSON，OpenCode 使用 JSONC。保存到应用项目数据目录，新会话使用配置快照；不能暗中覆盖用户主目录的全局配置。

## 实现状态与差距

上述主链路已有实现与工程测试。原生事件和审批覆盖取决于具体 CLI 版本；工程样例通过不等于所有模型、版本与真实长任务都已验证。后续适配需保留明确的未知事件处理与原生错误信息。
