## 创建与组织

拓扑工具栏提供“新建节点组”，也可多选节点后“组成节点组”。只填写名称即可保存；类别自由输入，说明和其他内容按需补充。

保存成功后打开组详情或定位到画布中的组。新组不自动创建实验、运行、设计或总结。可以混合不同类型节点，类别不限制成员类型。

成员编辑使用可检索、可分页的选择器；同一节点可选入多个组。新增、移除、角色修改和排序明确保存，取消不改变科研事实。排序提供上移/下移操作；为避免部分目录覆盖完整顺序，需载入全部直接成员并清除搜索后操作。

上级组候选排除自身与后代，后端仍检查循环和项目归属。移组前展示新的层级；冲突后保留用户输入并要求核对最新数据。

## 组详情

沿用 `/topology/groups/:id`，顶部显示名称、可选说明/类别/标签和成员计数；主入边/主出边存在时显示相邻对象的紧凑入口。操作为编辑核心、添加成员、添加内容块、添加关系，危险删除放在独立区域。

详情提供三个标签页，避免为空组增加多层工作流：

| 标签页 | 行为 |
| --- | --- |
| 成员 | 默认页；显示直接成员、子组，以及可切换的全部后代节点视图 |
| 研究材料 | 与文献相同的自由内容块、文件预览、编辑、原件和支持的导出 |
| 关系 | 组的正式入边/出边，以及独立入口查看成员范围的对外关系 |

成员默认一张紧凑表：名称、节点类型、成员角色、节点状态、简短说明。递归视图增加实际所属组和角色来源；按身份去重，但可展开多个加入位置。子组是明确的组入口，不冒充普通成员节点。

成员摘要来自当前对象，点击进入原节点详情；返回保留筛选与滚动。一个成员失败、丢失或不可用时明确标注，不使整张表无法阅读。

研究材料不预置“实验设计/结论”等必填栏目，也不自动拼接成员全文。可在组内写总结，也可关联独立总结节点，二者均无需互相复制。

## 关系编辑

从组详情或节点详情选择目标节点/组、方向、关系类型与可选说明。选择器明确显示对象种类，不能以同名猜测端点。

关系行可以指定为主入边/主出边，方向匹配后才可选择；各至多一个。选择其他主边只变更强调对象，原边保留。删除边时同步移除相应主边标记。

组的两种状态均保留容器边界与正式关系锚点；设计→组→总结的结构在缩略与展开时始终可理解。直接组关系、成员投影边及成员归属在视觉和文字上可辨别。

## 画布与浏览

- 收起组为紧凑容器，显示组名、总范围节点数和节点小点；小点承担缩略预览，容器整体与明确的展开按钮均可触发展开。共享成员计数有独立提示。
- 展开后正常节点位于可见容器内，子组形成内部容器。镜头对准目标容器，初始占画布约 75%～85%，保留外围连线空间。拖动组标题带动其中节点；拖动内部节点保持在容器范围内。
- 成员对外边可以按端点、方向、类型聚合；点击查看原关系及真实端点。直接组边不与投影边混成一种关系。
- 共享成员在多个收起组外保持可见；收起某组也不遮住其他展开组的直接共享成员。有所属组提示，可聚焦某组查看完整局部结构。
- 主边可强调，其他边仍保留；隐藏内部边时有数量与展开入口。
- 空组仍可显示、连接、编辑与删除；图上没有成员不代表组对象不存在。
- 搜索临时揭示成员路径；退出搜索恢复先前折叠，不写组修订或科研历程。
- 收起恢复展开前的镜头与根对象位置；嵌套进入支持返回上一级。快速切换和手动平移/缩放会中断旧动画，减少动态效果设置下即时到位。展开状态和位置按用户、项目保存，不能影响其他用户或 Agent 的正式读取。

桌面表格高信息密度，窄屏减少默认列或局部横向滚动。使用共享 SelectMenu、Dialog、普通比例字体、清晰焦点和已有配色；角色、状态与关系含义不能只靠颜色或悬浮提示表达。

## 人工修改、审批与删除

人工核心、成员、正文、主边及关系修改经同一科研变更机制保存。Agent 提交的组必须显示为候选，用户可预览名称、成员及角色、正文和关系后接受、拒绝或暂缓。

预览不把候选成员加入正式组，不把候选边画成正式关系。审批时检测原组、成员、关系、文件与权限变化，不能因候选已生成而跳过重新校验。

删除组前展示将移除的组关系与材料、保留的成员、子组提升位置，并输入原因。仅解除成员关系也需明确当前层级；不能将“从组中移除”做成“删除节点”。

科研历程记录组创建/编辑、成员角色与层级调整、材料修改、关系与主边修改、候选和删除。折叠、普通筛选和浏览不记科研变更。组删除后，历史仍能阅读当时身份与关键依据。

## Agent 体验

Agent 可搜索节点组，读取组概要，再按需分页看成员或子组。概要只提供核心、计数、主边、有限材料目录和精确读取提示；不加载所有成员正文、运行或曲线。

角色与层级按真实来源返回；“组有某条关系”不能被描述为“每个成员都建立了这条关系”。邻居探索区分组直接关系和成员范围对外关系。

Agent 使用现有候选创建/增量编辑流程写入组，无权自己审批。组内容上传、下载、来源与阅读回执使用共享机制；普通建组不要求发现所有 Schema 或学习内部事务。

## 关键验收场景

| 场景 | 必须可观察的结果 |
| --- | --- |
| 只填写名称 | 可保存空组，无强制角色、类别、设计或总结 |
| 一组文献逐步加入协议和表格 | 同一组身份与 URL，无需转成另一种组 |
| 实验设计→组→总结 | 收起时是含成员小点的紧凑容器；展开时镜头聚焦，外围保留两条连线，组端点不变 |
| 另加一条成员对外边 | 真实端点可查；不会自动消失或伪装成直接组边 |
| 多条入边/出边 | 全部可保存，各选一条主边，也可不选 |
| 成员属于两个收起组 | 共享成员仍可见，组计数准确，不随 ID 顺序换组 |
| 成员同时直接属于展开组与收起组 | 展开组仍能看到该节点，收起组标注共享成员 |
| 父子组多层且节点重复加入 | 无循环，递归计数去重，保留加入位置和局部角色 |
| 只从父组移除直接成员 | 若子组仍包含它，明确提示仍在递归范围 |
| 两人编辑同一成员集合 | 返回冲突，保留草稿，不覆盖未修改角色或顺序 |
| 删除组或删除成员节点 | 节点保留/引用清理符合业务规则，历史与文件仍可追溯 |
| 组正文上传真实 PNG、XLSX、TeX | 复用现有实际预览、编辑和导出，无第二套渲染器 |
| Agent 创建含成员/材料/组边的候选 | 接受前不进入正式图，接受后详情与图一致 |
| 非授权用户或 Agent 绕过 UI | HTTP/领域层拒绝相同越权操作 |
| 组含大量成员和长正文 | 概要不含全文，成员分页、范围与预算明确，旧游标被正确拒绝 |
| 搜索、收起、重启与切换项目 | 状态隔离，正式成员/关系及审批结果保持一致 |
| 收起容器的边框与预览 | 背景、标题、小点和点击区域位置重合，无漂浮图标或重叠拦截 |
| 展开子组后返回 | 容器占画布受限方向约 80%，返回恢复之前的镜头及祖先展开状态 |

具体实现检查按 [测试指南](../../playbooks/testing.md) 选范围。文档校验只证明链接和结构，功能完成必须有相应的领域、接口和少量真实浏览器证据。
