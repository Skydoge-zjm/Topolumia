# 文献阅读与保存需求

依据：[文献业务](../business/literature-node.md)。下面的行为已接入当前实现；列出的差距不代表完成。

## 研究者操作

1. 创建文献节点，填写最小节点名，再按需要补充书目信息。
2. 在核心信息之外自行添加、命名、排序内容块，不要求选择预设栏目。
3. 输入解释或指标，上传截图、Markdown、TeX、XLSX 等真实材料，或保存链接。
4. 在详情页阅读成果；预览和编辑切换呈现，不把渲染结果与完整表单同时堆叠。
5. 按需要打开原图、查看原文件或导出支持的表格格式。

人工输入和 Agent 候选接受后形成的内容，应使用相同详情展示。

## 验收行为

| 场景 | 必须可观察的结果 |
| --- | --- |
| 只知道论文常用名 | 可先创建，不强制补齐所有书目信息 |
| 改内容块标题 | 原指标条件、来源、表示、转录和其他未修改信息保持不变 |
| 上传带样式 XLSX | 预览支持范围内的合并单元格、粗体、对齐和样式；保留原文件 |
| 上传 TeX 表格 | 可预览支持语法的表格；具备本机编译器时提供编译表示，否则明确诊断 |
| 上传截图 | 实际展示图像，能够打开原图；图号、说明与来源不丢失 |
| 比较论文指标 | 数值、单位、条件与出处可以一并保存，不只留下脱离语境的数字 |
| 从表格绘图 | chart 引用同一对象的内联表格绘制折线、柱状、散点或面积图，保留来源表格入口 |
| 阅读代码与摘录 | 代码提供行号、高亮、复制和长内容折叠；摘录的原文与译文并排，窄屏改为上下排列 |
| 版本冲突 | 显示错误并提供重新载入，不静默覆盖或自动重试删除 |
| Agent 整理论文 | 候选包含实际阅读成果；预览与正式节点明确区分 |

这些是验收标准，当前任务通过与否仍需相应验证，不能用“字段存在”代替完整流程验收。

## 明确差距

- 通用 chart 读取内联表格，最多绘制 8 个数值系列；分类横轴最多展示前 60 行并显示截断提示。上传文件的表格预览不自动成为内联绘图数据，也不提供完整可视化配置编辑器。
- TeX 不是任意 LaTeX 项目编译服务；XLSX 不是完整 Excel 引擎，不承诺宏、公式重算和全部工作簿特性。
- 论文阅读 Skill 已提供方法指导，但有 Skill 和工具不代表每次真实阅读质量都达标，需要检查实际候选和原始证据。
- Markdown/HTML/PDF 的任意跨格式导出尚未统一交付；当前优先保证原文件与支持的表格导出。
