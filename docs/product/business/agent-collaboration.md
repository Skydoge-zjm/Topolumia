# Agent 与研究者协作

Agent 是研究任务的执行者与内容贡献者，人类负责目标、判断和按权限确认科研变更。工具可用不代表所有操作都可执行；模型输出也不自动构成研究事实。

## 理想工作方式

1. 理解用户目标，仅获取相关项目上下文；没有必要时不遍历整个拓扑。
2. 用检索定位对象，用精确读取取得需要的证据；概述不是完整阅读。
3. 使用自身文件、终端和图像工具研究材料、运行程序；应用只提供必要领域操作。
4. 把有价值的成果和来源写入可预览的候选，继续补充时采用增量编辑。
5. 最终回复说明交付、缺口与待确认事项，用户在候选卡中审阅。

科研接口提供对象级动作，内部事务、预留 ID 推算和文件存储细节不应成为模型必须掌握的工作步骤。论文阅读的方法由按需加载的 Skill 辅助，Skill 不存在不应阻止创建普通会话。

## 角色与身份

账号、项目成员角色、具体权限和 Agent 会话凭据是不同概念。Agent 凭据限定项目、会话、能力与有效生命周期；实际执行时仍需检查当前授权。

会话属于工作台中的持续协作单元。恢复会话必须保持同一用户可见会话与原生连续性；完整对话和工具展示使用统一模型，供应商协议差异留在适配层。

Agent 可以执行长任务，由原生运行时控制其限制，用户可以停止。应用不设置统一整回合倒计时，也不能因运行实例容量不足删除已保存历史。
