# Evidence and source coverage

For a focused question, read the relevant passage, figure or table and its conditions. For a long reading, keep a short working outline if useful; there is no required planning JSON or fixed number of findings.

Preserve sections, pages, figure/table IDs, dataset/split, units and comparison settings when they affect the conclusion. Distinguish author claims, directly reported results and your own analysis. Weaken or qualify claims whose evidence is missing; record partial coverage without implying the entire paper was read.

For method/system papers, explain input → transformation → output, training objective, inference/sampling and details necessary for the reproduction goal. Keep equations that clarify the mechanism and explain their operational meaning.

For empirical papers, preserve data collection, comparisons, uncertainty and validity threats. For benchmarks/datasets, distinguish construction/annotation protocol from model performance. For surveys, preserve taxonomy, comparison dimensions, coverage boundaries and representative evidence.

Read/extract the source once when possible, then consult specific ranges. Use native PDF/image tools where no readable index exists. Resolve a mismatched path in its parent directory before widening the search. A download or metadata receipt is not evidence of reading.

Save findings under user-appropriate block titles. The source, transcription, rendering and interpretation of one result can share a block. Keep useful drafts and assets if an interface error blocks submission, and state what was actually saved.
