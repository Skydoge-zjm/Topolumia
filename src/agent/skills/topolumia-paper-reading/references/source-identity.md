# Source identity and version

Prefer sources in this order:

1. user-provided local PDF or source file;
2. a local library item and attachment when available;
3. a previously accepted Topolumia asset with matching checksum and version;
4. DOI, arXiv or publisher metadata plus the corresponding PDF;
5. trusted open-access metadata and PDF providers.

Confirm at least two stable identity signals when possible: normalized title, DOI, arXiv ID, authors, year, venue and source checksum. A title-only match is insufficient when several versions or similarly named papers exist. If identity remains ambiguous, stop before creating a node or candidate and ask for a DOI, arXiv ID, local PDF or exact library item.

Do not overwrite a paper's core or existing reading block merely because a newer search result has the same title. Treat a new version as a new representation or a deliberate update with a source locator and version note. Preserve the original source asset and checksum.

Metadata can fill bibliographic fields, but it cannot stand in for method, results or limitations. A PDF download receipt only proves delivery; it does not prove that the Agent read the pages.
