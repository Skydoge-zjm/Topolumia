# Evidence and numerical results

Keep original evidence and derived material distinct: a screenshot is a source representation, an XLSX transcription is a transcription, and re-typeset TeX is a rendering. State OCR/reading uncertainty. Do not invent missing values, substitute zero, or silently discard footnotes or merged header context.

A useful result includes method, dataset and split, metric/unit, condition, comparison direction and source location. Report mean/deviation or repeated seeds when supplied. Do not merge results from different settings into one best number.

For spreadsheets, distinguish raw `0.762` from displayed `76.2%`. Preserve strings, negative numbers and empty cells. Formula values may be cached; no cached formula value is not a measured zero. A UI preview limit is not a complete workbook: request the correct sheet and range or use the original asset.

Record figure/table number, section, verified page and original URL or asset where available. Never invent a page number. `interfaceDelivered` means Topolumia returned that exact range; `agentReported` means the Agent read it with native tools and reported its location; `humanRecorded` identifies manual entry. None of these alone means the scientific interpretation is confirmed.
