# Paper-type emphasis

Use the type to decide what deserves depth, not to impose fixed block titles.

| Type | Emphasis |
| --- | --- |
| method/system | mechanism flow, objective, training/inference, complexity, ablations and reproduction settings |
| benchmark/dataset | data source, construction/annotation, task definition, splits, baseline protocol, coverage and bias |
| empirical/clinical | cohort or sampling, instruments/labels, analysis protocol, uncertainty, validity and generalization |
| survey/review | taxonomy, selection scope, comparison axes, missing areas and representative evidence |
| humanities/social science | corpus, interpretation method, historical/contextual evidence, counter-readings and scope |

For papers crossing types, use the emphases relevant to the task. Do not infer a method paper's success from an abstract claim when the reported comparison or ablation is missing.
